# TermLens

Windows 桌面选词解释工具。选中文字后按 `Ctrl+Shift+Space` 打开浮窗，查看解释、点击术语、继续追问。也可以开启默认关闭的“选中即解释”。

启动后先出现轻量浮窗，无需输入或导入文章；请到正在使用的软件里选词。输入框默认收起，粘贴和编辑只是备用入口。

浮窗右上角的 `×` 可随时关闭浮窗，程序继续在托盘运行；按 `Ctrl+Shift+Space` 再打开。未选中新文字时会保留原解释、对话和未发送的追问；选中新文字时按原有选词流程打开。有未发送追问时会先提示新选区等待处理。完全退出程序可使用托盘菜单“退出”。

## 当前功能

- 独立桌面浮窗；记录与设置在主窗口中管理。
- 本地词库识别与解释；可选 AI 补充分词、解释和追问。
- 选中文段内的术语可点击；相关概念可逐层展开和返回。
- 接受的选中文字、解释和已发送追问保存到本机 SQLite 数据库，重启后可查。
- 支持配置 OpenAI 兼容、Anthropic、Gemini 服务。密钥由 Windows 本机加密后存储，不回显原值。
- 网络失败保留已发送问题并显示错误；不会生成虚构的成功结果。

## 启动

需要 Windows 10/11、Node.js 22.12 或更新版本，以及 npm。将项目放在希望保存程序和数据的目录。

```powershell
npm ci
npm run build
powershell -NoProfile -ExecutionPolicy Bypass -File .\Start-TermLens.ps1
```

启动脚本默认把记录、设置、缓存、日志和临时文件放入本项目 `data` 目录。也可使用 `-DataDirectory D:\TermLensData` 指定其他绝对路径。直接执行 `npm start` 会使用操作系统默认用户目录；需要避免 C 盘写入时请使用启动脚本。

依赖安装并构建完成后，也可以双击 `Start-TermLens.cmd`；已有文件夹打包版本时，它优先启动该版本。

配置 AI：打开“记录与设置”中的服务设置，填写公开接口 URL 和自己的密钥，点击“获取模型列表”，从列表选择模型，填写服务名称后保存并测试连接。获取列表无需先填模型名称或保存；服务不支持列出模型时仍可手动填写。列表表示服务返回的模型目录，能否实际调用以连接测试为准，文字解释应选择文字模型。

仅填写域名时，OpenAI 兼容服务自动补 `/v1`，Gemini 自动补 `/v1beta`，自定义路径保留。Anthropic 使用基础地址，程序追加 `/v1/models` 和 `/v1/messages`。URL 允许 HTTPS 或本机 HTTP；不得在 URL 内携带密钥。更换已保存服务的地址或协议后，需要重新输入密钥，避免旧密钥被误发给新服务。没有配置服务时，本地词库仍可用，未知术语和追问会提示配置服务。

## 边界与隐私

选词使用 Windows UI Automation，即应用向操作系统提供的文字选择接口。应用没有提供该接口时，无法可靠读取选区，可以在浮窗中粘贴。第一版不保证兼容全部浏览器、PDF 阅读器、游戏或管理员权限窗口。

自动解释仅在开关开启时检查当前选区；不会记录全部按键、不会改写剪贴板，并排除密码控件和自身窗口。接受的选区会本地保存。启用 AI 分词、请求 AI 解释或追问时，相应文字和当前对话会发送给你配置的服务；第三方如何保留数据取决于该服务。没有云端备份。

手动编辑的阅读原文需点击保存；未发送的追问只保留在当前窗口内存。请勿把项目 `data`、数据库、真实配置或日志上传。清空阅读原文记录不会同时删除已保存的概念对话。

配置保存遇到普通写入错误会尝试恢复原凭据；断电发生在两个配置文件写入之间，或磁盘损坏导致回滚也失败时，仍可能需要重新填写服务配置。

本地词库是有限的通用示例，模型解释也可能出错。语音、录屏、OCR 和跨设备同步不属于当前版本。

## 验证与构建

```powershell
npm test
npm run build
npm run test:native
npm run test:browser-selection
npm run test:ui
npm run pack:win
```

原生与界面测试会创建专用测试窗口、短暂取得焦点并检查选区；请在没有其他键盘操作时运行。界面测试使用本机模拟 AI 服务，无需真实密钥，不代表真实模型的解释质量。截图和测试数据位于忽略上传的 `qa` 目录。

浏览器选词检查使用安装在本机的 Edge、独立测试资料目录和启用的辅助功能接口。它验证普通网页中的中文选区，不代表已验证 Word、全部 PDF 阅读器或所有网页控件。

`pack:win` 生成 `release/win-unpacked` 的 Windows x64 文件夹版本，未进行代码签名。验证记录和已知限制见 [任务文档](docs/CORE_READER_TASK_20260908.md)。

## 技术

Electron 提供窗口、托盘、快捷键和主进程；React/TypeScript 构建界面；CSS 控制排版与显示状态；Windows UI Automation 读取选区；SQLite 持久保存记录。前端仅能调用预先列出的内部接口，所有输入在主进程再次校验。

参考项目：[YouTube Digest](https://github.com/zarazhangrui/youtube-digest)，MIT 许可。此版本保留 TermLens 自身桌面实现，没有复制其代码。源代码公开可供查看；当前尚未授予开源再分发许可。
