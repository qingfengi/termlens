## 界面方案

- 默认进入阅读器，导航仅保留阅读器与设置，去除未完成的语音、学习占位页。
- 桌面为原文与解释两列；宽度小于 800 像素时顺序排列，390 像素宽度使用固定字号和可换行布局。
- 原文可编辑、命名、保存、新建，打开原文库后可读取或删除保存的内容。丢弃未保存修改前确认；删除保存记录仍保留当前文字。
- 识别采用 `termDetect({ text, useAi })`，AI 补充识别默认关闭。编辑原文后清除旧范围标注，忽略已经失效的识别结果。
- 标注使用原文字符范围及 React 文本节点，验证范围、表面文字与重叠，不使用 `dangerouslySetInnerHTML`。术语按钮支持 Tab、Enter、Space 和清晰焦点。
- 悬停或键盘聚焦 250 毫秒后读取简释，命中缓存时不重复请求。过期响应不重新打开已经离开的提示。
- 点击术语读取详解，子概念逐级创建路径，面包屑回到原有对话。学习记录通过父线程关系恢复路径，并检测循环引用。
- 追问输入按线程独立保留。成功才清空对应输入并更新对话；失败再次读取数据库记录，只有实际读到该问题时才显示“问题已保存”。失败时可编辑输入重试或重新读取记录。
- 切换至设置时阅读器保持挂载，原文和未发送追问仍保留在内存中。
- 设置支持三种已有协议、名称、URL、模型、超时、重试次数、默认术语服务、保存、测试与删除。连接测试只针对已保存配置，修改未保存时禁用测试。

## 凭据边界

- 仅在用户填写的密码输入框及提交请求的短暂内存中持有新 Key。
- 从主进程取得的 Key 是掩码，不放入密码框。留空保存表示保留现有掩码对应凭据；明确勾选移除才清空。
- 保存成功后重新用安全配置填充表单，密码输入立即清空。
- 不使用 localStorage，不记录 Key，不内置个人服务或凭据。默认表单地址为公开官方 URL，填写表单不发送网络请求。
- 凭据存储和 IPC 返回值脱敏以主进程实现为准，界面不能替代该安全边界。

## 限制与交接

本子任务只完成前端静态类型验证，不能替代真实持久化、模型响应和 Electron 联调。原文需要明确点击“保存原文”；尚未保存的文字和未发送追问保留在当前应用内存，关闭应用后不保证恢复。公开发布前由主任务确认这一保存范围与用户预期一致。网络取消由请求序号防止界面误更新，当前 IPC 契约未提供终止已经发出的模型请求的能力。
